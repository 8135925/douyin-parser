抖音视频解析无水印 · 音频转文字

粘贴抖音分享链接，提取标题 / 简介 / 封面 / 无水印视频，支持下载视频、提取音频、音频转文字

设置：解析服务、媒体代理、转写模型（默认已配置好，通常无需修改）

已默认为你配置好一个在线解析服务，无需任何设置即可直接解析链接。它是本工具自带的 Node 服务（源码见本项目 api/parse.js 与 lib/douyin.js），服务端完成「短链跳转 → 取 ttwid → 手机 UA 请求分享页 → 提取 _ROUTER_DATA → playwm 换 play 得无水印地址」。若该服务不可用，可换成你自己的任意解析接口，页面会自动适配常见返回格式。

抖音 CDN 不返回跨域头，浏览器无法直接 fetch 视频字节。已默认指向在线解析服务的中转端点（支持 Range，可拖动播放），因此原片下载、音频提取、转文字都能一键完成。填写或更换「解析接口」时会自动同步带出。

ttwid 来自抖音首页下发的 Cookie，一般长期有效。失效时点「获取新的」自动抓取，或手动粘贴。

支持 App「复制链接」得到的口令文本（自动提取其中的链接）、v.douyin.com 短链、www.douyin.com/video/xxx 长链、iesdouyin.com 分享链接。
